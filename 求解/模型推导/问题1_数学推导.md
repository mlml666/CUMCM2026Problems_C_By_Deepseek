# 问题1 数学推导：完美信息下的日计划购电优化模型

> 阶段：Phase 1 推导 | 依赖：`00_符号与共同模型.md`（符号、口径、命题 A1–A3）
> 对应框架设计命题1：完美信息下最小购电费计划可由确定性 LP 精确求得，且最优充放电呈"低价充、高价放"的套利结构。

---

## 1. 问题与信息结构

**已知（0:00 时全部可得）**：当天 144 个时段的电价 $p_t$（附件1）、小区负载 $L_t$（附件1）、光伏发电预测功率 $P_t$（附件1）。

**要求**：
1. 微网提供的电能不低于小区负载；
2. 储能 0:00 与 24:00 储电量相同（$E_{144}=E_0$）；
3. 在 0:00 制定当天计划购电策略，使全天购电费最小。

**未知/不确定**：无。问题1 是**完美信息的确定性优化**，因此它是问题2–4 的"内核"与最优性下界参照（问题2–4 的完美信息最优值即由它给出）。

## 3. 模型建立

### 3.1 决策变量

$$\mathbf{x}=\Big(\{g_t\}_{t=1}^{144},\{a_t\},\{b_t\},\{s_t\},\{E_t\}_{t=1}^{144}\Big)\in\mathbb{R}^{720}_{+}$$

变量含义见 `00_符号与共同模型.md` §2.2（$g$ 购电、$a/b$ 电池侧充/放电、$s$ 弃光、$E$ 时段末储电量）。

### 3.2 目标函数

$$\min_{\mathbf{x}}\; F_1(\mathbf{x})=\sum_{t=1}^{144}p_t\,g_t \qquad (\text{元}) \tag{1.1}$$

即全天购电费（购电量按交易时刻电价计价）。

### 3.3 约束条件（逐条编号，论文正文可直接引用）

| 编号 | 公式 | 含义 |
|------|------|------|
| (1.2) | $g_t+\eta_db_t+P_t\Delta t=L_t\Delta t+\dfrac{a_t}{\eta_c}+s_t$ | 母线功率平衡（购电+光伏+放电=负载+充电+弃光），与共同模型 C1′ 一致 |
| (1.3) | $E_t=E_{t-1}+a_t-b_t$ | 储能动态（电池侧吞吐，$\eta$ 已在(1.2)体现） |
| (1.4) | $E_{144}=E_0=6000$ | 日周期边界（题目要求） |
| (1.5) | $1200\le E_t\le10800$ | SOC 安全区间（附录1） |
| (1.6) | $0\le a_t\le\bar A,\quad 0\le b_t\le\bar A,\quad \bar A=5000\Delta t=833.33$ | 充/放电功率上限 |
| (1.7) | $g_t\ge0,\;s_t\ge0$ | 不可售电、弃光非负 |
| (1.8) | $g_t+\eta_db_t+P_t\Delta t\ge L_t\Delta t$ | 供电不低于负载（由(1.2)(1.7)自动满足，列出以对应题目表述） |

其中 (1.8) 是冗余约束（由 (1.2) 与 $s_t\ge0$ 推出），保留在模型中不增加求解负担，但**必须在论文中说明其来源**，避免评委质疑"漏约束"。

**量纲核对**：目标 (1.1) 为 (元/kWh)×(kWh) = 元；约束 (1.2) 各项均为 kWh（功率 × 1/6 h）；(1.3) 为 kWh；功率上限 (1.6) 由 $5000\ \text{kW}\times\frac16\ \text{h}=833.33$ kWh 换算而来。完整量纲分析见 `00_符号与共同模型.md` §3。

### 3.4 标准 LP 形式

令 $\mathbf c$ 为仅在 $g_t$ 位置取 $p_t$、其余为 0 的费用向量，则

$$\min\;\mathbf c^{\!\top}\mathbf x\quad \text{s.t.}\quad A_{\text{eq}}\mathbf x=\mathbf b_{\text{eq}},\quad \mathbf l\le\mathbf x\le\mathbf u \tag{1.9}$$

- 等式约束：144 条 (1.2) + 144 条 (1.3) + 1 条 (1.4) = **289 条**；
- 不等式约束：$2\times144$ 条 (1.5) + 288 条 (1.6) + 288 条 (1.7) ≈ **864 条**（实际实现中 $g,a,b,s$ 的非负与上界用变量界表达，仅 (1.5) 与 (1.6) 的上界进约束矩阵）；
- 变量：**720 个**，全部连续 → 问题为**线性规划（LP）**，规模极小。

## 4. 模型性质与最优解结构

### 4.1 可行性

$s_t$ 可自由吸收光伏盈余、$g_t$ 可无限补足缺口，故只要 $E_0$ 落在 $[1200,10800]$ 且日周期条件可通过充放电实现，(1.2)–(1.7) 恒可行。取 $a_t=b_t=0$、$g_t=\max\{0,(L_t-P_t)\Delta t\}$、$s_t=\max\{0,(P_t-L_t)\Delta t\}$ 即得一个可行解，故**问题1 必有最优解**（目标下有界：$F_1\ge0$）。

### 4.2 命题 1.1（全天购电量分解）

由 `00_符号与共同模型.md` 命题 A2，取 $E_{144}=E_0$：

$$\sum_t g_t=\underbrace{\sum_t(L_t-P_t)\Delta t}_{55542\ \text{kWh(附件1)}}+\sum_t s_t+0.2111\,A,\qquad A=\sum_t a_t=\sum_t b_t$$

**管理含义**：全天购电量 = 净缺口 + 弃光 + 储能往返损耗；储能不会"创造"电量，其价值完全来自**时段间的价格搬运**（把低价电搬到高价时段）。

### 4.3 命题 1.2（套利判据与阈值策略）

由命题 A3，电池侧搬运 $A$ 的电量、在时段 $t_c$ 充、$t_d$ 放，费用变化为

$$\Delta F=A\left(\frac{p_{t_c}}{\eta_c}-\eta_d\,p_{t_d}\right) \tag{1.10}$$

- $\Delta F<0$（值得搬运）$\iff \dfrac{p_{t_d}}{p_{t_c}}>\dfrac{1}{\eta_c\eta_d}=1.235$；
- 最优策略为阈值策略：存在电量影子价格 $\lambda$（元/kWh），**$p_t<0.9\lambda$ 时充电、$p_t>1.111\lambda$ 时放电、其余闲置**；
- $\lambda$ 由 $E_{\min}/E_{\max}$、功率上限 $\bar A$ 与日周期条件内生决定：容量与功率越紧，$\lambda$ 越接近充电与放电电价的边界。

**用附件1 数据核对套利机会**（小时均电价：夜 0.427–0.439、早峰 8 时 1.081、午间 11 时 0.473、14 时 0.954、晚峰 18–20 时 1.274/1.348/1.265、22 时 0.418）：

| 充电窗口 | 电价 | 放电窗口 | 电价 | 价比 | 是否套利 |
|---------|------|---------|------|------|---------|
| 22:00–4:00 | ≈0.42 | 18:00–20:30 | ≈1.30 | 3.10 | ✅ |
| 11:00–12:00 | ≈0.47 | 18:00–20:30 | ≈1.30 | 2.77 | ✅ |
| 0:00–4:00 | ≈0.43 | 8:00–9:00 | ≈1.03 | 2.40 | ✅ |
| 11:00–12:00 | ≈0.47 | 13:00–14:30 | ≈0.92 | 1.96 | ✅ |
| 15:00 | ≈0.74 | 18:00–20:30 | ≈1.30 | 1.76 | ✅ |
| 11:00 | 0.473 | 15:00 | 0.742 | 1.57 | ✅（边际） |
| 4:00 | 0.439 | 8:00 | 1.081 | 2.46 | ✅ |

**结论**：附件1 的价格曲线（夜间谷、午间次谷、早晚双峰）为储能提供了大量满足 $1.235$ 门槛的套利机会，最优解必然表现为"夜间与午间充满、早峰与晚峰放空、日末回充至 6000"的结构，且受 $\bar A=833.33$ kWh/段约束，充放电在时间上呈"陡坡"而非瞬时切换。

### 4.4 关于同时充放电

由命题 A1，最优解中 $a_tb_t=0$，故**本模型用 LP 即可，不需要引入 0-1 变量**（若强行加入"互斥"约束会变成 MILP，且不会改变最优值）。

## 5. 求解算法与实现要点

| 项目 | 方案 |
|------|------|
| 主算法 | 单纯形/内点法 LP；本机 `scipy.optimize.linprog(method='highs')`（已验证 scipy 1.13.1 可用） |
| 规模 | 720 变量、约 289 等式 + 864 不等式；HiGHS 求解时间 < 0.1 s |
| 矩阵构造 | 用 `scipy.sparse` 按"时段块"装配：每段 5 列（g,a,b,s,E）→ 变量分块布局，避免稠密 720×1153 矩阵 |
| 变量布局建议 | $\mathbf x=[\mathbf g;\mathbf a;\mathbf b;\mathbf s;\mathbf E]$，块内按 $t$ 连续，便于向量化构造 |
| 备选求解 | `pulp`/`cvxpy`（本机未安装，Phase 2 如需可补装）；`E_t$ 用前缀和消元可降至 576 变量 |
| 数值注意 | 电价量级 0.37–1.40、能量量级 $10^3$–$10^4$，条件数良好；无需归一化，但建议把目标函数写成"元"而非"千元"避免舍入 |
| 后处理 | 由 $g_t,a_t,b_t$ 汇总到表1、表2；核对 A2 恒等式残差 $<10^{-6}$ |

**求解流程（伪代码）**

```
读取附件1 → 构造 c, A_eq, b_eq, bounds（按 §3.4）
求解 LP（HiGHS, presolve=True）
若 status != 0：检查 E_144=E_0 可行性与界设置
输出 g_t, a_t/0.9（充电量）, 0.9 b_t（放电量）, E_t
核对：Σg − (缺口 + Σs + 0.2111Σa) ≈ 0；E_144 = E_0 = 6000
按 §6 映射写入 result1.xlsx，并生成表1/表2 数据
```

## 7. 备选模型与对比（论文"模型对比"章节素材）

| 模型 | 建模思路 | 与 LP 的关系 | 对比价值 |
|------|---------|-------------|---------|
| **LP（主模型）** | §3 | — | 全局最优、毫秒级、可给对偶解释 |
| DP | 状态 $E_t$ 离散化（1200–10800，步长 100 → 97 状态），阶段 $t$，动作（充/放/闲置），递推 $V_t(E)=\min\{\text{本段费用}+V_{t+1}(E')\}$；终端条件 $E_{144}=E_0$ | 网格最优；步长→0 时收敛到 LP 最优值 | 独立验证 LP 结果（Phase 2.5 用它核对目标值，分歧应 <1%） |
| MILP | 在 LP 上加 $a_t\le\bar A z_t,\ b_t\le\bar A(1-z_t),\ z_t\in\{0,1\}$ 强制互斥 | 由命题 A1，最优值不变（可作为"验证命题 A1"的数值实验） | 论文中说明"为何不需要 MILP" |
| 贪心规则 | 按电价排序，低价时段充满、高价时段放空，手工排程 | 一般次优（受功率上限与 SOC 约束影响） | 作为基线，量化 LP 的优化收益 |

## 8. 验证与敏感性分析

**验证（Phase 2.5 必做）**
1. **能量守恒**：命题 A2 恒等式残差 $|\sum g_t-(\text{缺口}+\sum s_t+0.2111A)|\le10^{-6}$；
2. **边界**：$E_0=E_{144}=6000$，且 $\min_tE_t\ge1200$、$\max_tE_t\le10800$；
3. **功率**：$\max_t a_t,\max_t b_t\le833.33$；
4. **独立交叉**：DP（步长 100 kWh）目标值与 LP 目标值相对偏差 <1%；
5. **基线对比**：无储能基线费用 $F_0=\sum_tp_t\max\{0,(L_t-P_t)\Delta t\}$，LP 最优费用应显著低于 $F_0$（差额即储能套利收益），且差额可由储能吞吐量 $A$ 与价差解释。

**敏感性分析（OAT + 龙卷风图）**

| 参数 | 扰动 | 观察量 |
|------|------|--------|
| $\eta_c=\eta_d$ | 0.9 → 往返 90%（各 $\sqrt{0.9}$）、0.85、0.95 | 全天购电量、费用、储能吞吐量 $A$ |
| $E_{\min}$ | ±10%（1080/1320） | 费用与放电深度 |
| $\bar A$ | 5000 kW → 4000/6000 kW（含母线侧口径） | 是否出现功率瓶颈 |
| $E_0$ | 6000 → 1200/10800 | 日周期条件的影响 |
| 电价形状 | 附件1 整体缩放 ±10% | 套利窗口是否变化（阈值 1.235 的稳健性） |

**预期稳健性结论**：只要早晚峰与夜/午谷的价比维持 >1.235 的数量级（附件1 实测 1.8–3.1，余量充足），最优策略的结构（夜充—峰放—日末回充）不会改变，仅储能吞吐量与费用数值变化；这一点在论文中作为"策略稳健性"给出。
